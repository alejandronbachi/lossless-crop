[Hotkeys Layout]

[Space] : Crop & Next
[S] : Crop & Stay
[O] : Open Directory
[I] : Open Image
[F/D] : Skip Forward
[B/A] : Skip Backward
[R] : Rotate Clockwise
[P/Q] : Toggle Preview
[Alt] : Toggle Menu
[Esc] : Exit App

Left-Click Drag: Draw Box
Right-Click Drag: Move Box
Middle-Click: Crop
Scroll: Navigate
