# 🎨 FastCrop Key Features & Controls

## 📁 Folder Intake
Selects a target directory and safely isolates readable image files (`.jpg`, `.jpeg`, `.png`, `.webp`).

## ⌨️ Keyboard Navigation & Operations
* **Space:** Save current selection crop and advance to the next file.
* **S:** Save current selection crop and remain on the current file.
* **F:** Forward to the next file (skip without cropping).
* **B:** Backward to the previous file (skip back).
* **R:** Rotate image 90 degrees clockwise instantly.
* **Esc:** Gracefully close the application.

## 📐 Aspect Ratio Enforcement
A dropdown configuration allowing users to snap the mouse selection to freeform bounding boxes or explicit proportions (`1:1`, `16:9`, `4:3`).

## 💾 Persistent Geometry States
A togglable rule that determines whether advancing to a new image keeps your exact selection box dimensions and positions intact, or resets back to raw canvas defaults.
